htmlppt · htmldeck/v1

A deck your agent can edit

Every object is plain HTML with a stable id. Change text, styles, or structure, then validate before saving.

Open with the promise: the deck is ordinary HTML, so an agent and a person can edit the same file.

How a deck is built

  • One <section> per slide with a unique data-slide-id.
  • Every top-level object carries data-ppt-el.
  • Speaker notes are a direct-child <aside data-ppt-notes hidden>.
Keep object ids stable. The editor and MCP tools address objects by these ids.
