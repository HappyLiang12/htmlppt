# Security

htmlppt runs locally. The editor host binds to `127.0.0.1` on a random port and
requires the per-session token generated by `htmlppt open`. It serves only the
opened deck and the packaged editor assets, and confines HTML/PDF/PNG exports to
the deck directory. Deck previews use an iframe sandbox without script
execution; unsaved drafts live only in the editor origin's IndexedDB and never
contain the session token.
PDF/PNG rendering runs Chromium with JavaScript disabled and blocks file,
network-navigation, frame, worker, and script requests. The MCP server uses
stdio only. Direct mode reads and writes the paths you give it; host-attached
mode routes through the token-authenticated host. The package has no telemetry
and makes no remote calls except loading a deck's own image, font, and
stylesheet assets.

See the repository `SECURITY.md` for the full threat model.

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately through
the repository's GitHub Security Advisories ("Report a vulnerability") with:

- the htmlppt version and operating system,
- reproduction steps or a minimal deck,
- the impact you observed.

Please allow time for a fix before public disclosure.
