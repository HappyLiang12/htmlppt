# Security

htmlppt runs locally. The editor host binds to `127.0.0.1` on a random port and
requires the per-session token generated by `htmlppt open`; it serves only the
opened deck, the packaged editor assets, and HTML export. The package has no
telemetry and makes no remote calls except loading a deck's own assets in the
browser.

## Reporting a vulnerability

Do not open a public issue for a security problem. Report it privately through
the repository's GitHub Security Advisories ("Report a vulnerability") with:

- the htmlppt version and operating system,
- reproduction steps or a minimal deck,
- the impact you observed.

Please allow time for a fix before public disclosure.
